# Stickman Duel Web (Pure Frontend)

一个“火柴人对决/乱斗”风格的纯前端小游戏（单个 `index.html`），无需后端，直接用浏览器打开即可运行。

## 运行
- 直接双击打开 `index.html`
- 或者用 VSCode Live Server / 任意静态服务器

## 操作
- 玩家1：A/D 移动，W 跳，F 攻击/开火
- 玩家2：←/→ 移动，↑ 跳，/ 攻击/开火
- ESC：返回菜单

## 模式
- 单人：你 vs AI（可调难度）
- 双人：本地同屏对战
- 生存：波次刷怪，尽量活得更久
